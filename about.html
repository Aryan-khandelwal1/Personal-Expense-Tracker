About SpendWise

A student project for everyday money management.

PERSONAL EXPENSE TRACKER

Know where your money goes.

SpendWise is a front-end web application designed to help users record income and expenses, set a monthly budget, and understand spending patterns in one place.

Project objectives

What this website is designed to do

↕

Track transactions

Add, search, filter, and remove income or expense records.

◷

Manage budgets

Set a monthly spending limit and monitor how much remains.

▥

View reports

Compare income and expenses and see category-wise spending.

▣

Store locally

Use browser localStorage to keep entries on this device.

Technology stack

✦

JS
JavaScript

How it works

Simple application flow

  1. 1
    Enter a transaction

    Fill in its description, type, amount, category, and date.

  2. 2
    Save the record

    JavaScript updates the browser's localStorage.

  3. 3
    Review your finances

    The dashboard, budget page, and reports use saved records.

Scope and future improvements

This is a front-end demonstration project. Data is saved only in the current browser on this device; it does not use a server or bank connection. Future versions could include user login, cloud backup, recurring transactions, and PDF reports.
