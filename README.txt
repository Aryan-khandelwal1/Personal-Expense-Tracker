SPENDWISE — PERSONAL EXPENSE TRACKER
=====================================

Files
- index.html          Dashboard
- transactions.html   Add, search, filter, delete, and export transactions
- budget.html         Set a monthly budget and review category spending
- reports.html        Income/expense comparison and summary insights
- about.html          Project overview and technology stack
- style.css           Responsive styling
- app.js              JavaScript logic and browser storage

How to run
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Double-click index.html or open it in a browser.
4. Click "Add transaction" to add sample entries.
5. Use the sidebar to present the five pages to your teacher.

Features
- Responsive layout
- Income and expense entries
- Dashboard totals and category breakdown
- Search and filter transactions
- Delete transactions
- Monthly budget tracking
- Reports and category summaries
- Export transactions as CSV
- localStorage persistence in the current browser

Important note
This is a front-end academic demo. Data is stored in the current browser only.
It does not connect to a bank, server, or online account.

Presentation suggestion
Start on Dashboard, add an expense and an income, show Transactions search/filter,
set a budget, open Reports, and finish on About Project to explain HTML, CSS, and JS.
